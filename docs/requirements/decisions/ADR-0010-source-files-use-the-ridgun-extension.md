# ADR-0010 — Source files use the `.ridgun` extension

## Context
Ridgun source files used `.rg`, library bundles `.rglib`, and `ridgunc compile` wrote `.rgc`. The Rogue language already uses `.rg`. Editors, GitHub and file managers then show Ridgun files as Rogue, and a search for `.rg` finds the other language.

`.rgc` was never bytecode: it was the checked source with a header line, and nothing read it. The bytecode VM (`vm.rg`) ran only in a demo printed by `ridgunc` with no arguments.

## Options considered
1. **Keep `.rg`.** No work; the clash with Rogue stays.
2. **Another short extension (`.rgn`, `.rdg`).** Still a two- or three-letter guess that another tool may own.
3. **The language name: `.ridgun`, `.ridgunlib`.** The pattern of Swift (`.swift`, `.swiftmodule`) and Mojo (`.mojo`, `.mojopkg`). Unambiguous; a few more characters to type.

## Decision
Option 3.

- **Source files:** `.ridgun`. This includes `build.ridgun` and `plugins/*.ridgun`.
- **Library bundles:** `.ridgunlib`. The bundle header is `-- RIDGUNLIB1`.
- **`.rgc` is removed,** with `ridgunc compile`, `stable compile` and the bytecode VM. `ridgunc` with no arguments prints its help.

`ridgunc` and `stable` SHALL still read the old names. In each place they look, the new name comes first, then the old one:
- `foo.ridgun`, then `foo.rg`;
- `foo.ridgunlib`, then `foo.rglib`;
- `build.ridgun`, then `build.rg`.

An import that names its file finds it under either name, so `import "io.rglib"` reads `io.ridgunlib`.

New files are always written with the new names: `stable new`, `stable init`, `stable add` on a project without a build file, and `ridgunc build --lib`.

## Consequences
- **Projects that keep the old names build unchanged.** By decision of the project owner, solstice, edtech and calipso keep them for now. They can rename with the steps in `docs/lang/file-extensions.md` whenever they want.
- **Repositories renamed in 1.0.10:** ridgun, libs, omni, unix-tools, www-ridgun, the web and db apps, ecosystem/libs/db, wildcat, the text editors and AIX. Files are renamed with `git mv`, so their history is kept.
- **Copies are not renamed.** Files under `.stable/deps`, `.stable/addons-old` and `target/` are regenerated by the next `stable deps` or `build`.
- **Editors:** the VS Code, gedit and Emacs modes open both the new and the old names.
- **Historical records are not rewritten.** Completed tasks and earlier ADRs keep the names they were written with.
- **Code:** one list of extensions in `parser.ridgun` (`source exts`, `library exts`) replaces the `.rg` repeated in each lookup. `stable` has `source path of` and `build file`.
