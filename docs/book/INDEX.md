# docs/book/ — The Ridgun Book (Multi-Language Editions: ES, EN, PT, SV)

| Path | What | Read when |
|---|---|---|
| `index.html` | Root interactive HTML book entry point (defaults to Spanish with ES/EN/PT/SV language selector) | Opening the book from the root `docs/book/` folder |
| `build_book.py` | Builder script that generates `es/index.html`, `en/index.html`, `pt/index.html`, `sv/index.html`, and root `index.html` | After editing any book chapter in `es/`, `en/`, `pt/`, or `sv/` |
| `es/INDEX.md` | El Libro de Ridgun — Edición en Español (Capítulos 00–08 + `es/index.html`) | Reading or updating the Spanish edition of the book |
| `en/INDEX.md` | The Ridgun Book — English Edition (Chapters 00–08 + `en/index.html`) | Reading or updating the English edition of the book |
| `pt/INDEX.md` | O Livro do Ridgun — Edição em Português (Capítulos 00–08 + `pt/index.html`) | Reading or updating the Portuguese edition of the book |
| `sv/INDEX.md` | Boken om Ridgun — Svensk utgåva (Kapitel 00–08 + `sv/index.html`) | Reading or updating the Swedish edition of the book |
