# core-lessons-learnt-notes

Generated by `aix lessons index` from `lessons/*.md`. Never edit this file: add, merge or prune the lesson files with
`core-lessons-learnt`, then run `aix lessons index`. Each line is a rule; open its file for why and when it applies.
`person` lessons are one user's preference: apply them when that author is the one you work with.

- Write all code examples, identifiers, and comments in technical documentation in English; reserve Spanish examples strictly for the Spanish book. (project, pedro@obdin.com) [lessons/english-code-examples-in-docs.md](lessons/english-code-examples-in-docs.md)
- Always pass -c user.name='Pedro Corral' and -c user.email='pedro@obdin.com' on every git commit command. (project, pedro@obdin.com) [lessons/git-commit-identity.md](lessons/git-commit-identity.md)
- Always use natural spaces instead of underscores in Ridgun function names, built-in calls, and tuple/sequence type signatures. (project, pedro@obdin.com) [lessons/natural-spaces-in-ridgun-names-and-types.md](lessons/natural-spaces-in-ridgun-names-and-types.md)
- Never touch ~/.local/bin/ symlinks or overwrite bin/ridgunc and bin/stable until the candidate binary in target/ is 100% verified and fast. (project, pedro@obdin.com) [lessons/never-overwrite-bin-until-verified.md](lessons/never-overwrite-bin-until-verified.md)
- Never run objdump, gdb, or binary disassembly/cave-scanning on ELF binaries, place executable code in ELF headers, or patch compiled binaries. (project, pedro@obdin.com) [lessons/no-elf-cave-scanning-or-binary-patching.md](lessons/no-elf-cave-scanning-or-binary-patching.md)
- Never add Python scripts to the repository; use pure Ridgun (`ridgunc run` / `stable`) or POSIX/Bash scripts (`*.sh`) for tooling and test runners. (project, pedro@obdin.com) [lessons/no-python-scripts-in-repo.md](lessons/no-python-scripts-in-repo.md)
- Never use shortcuts, host wrappers, or partial subsets when asked for a full implementation; never claim completion until 100% of features are ported. (project, pedro@obdin.com) [lessons/no-shortcut-or-partial-implementations.md](lessons/no-shortcut-or-partial-implementations.md)
- Increment the patch version (+0.0.1, keeping below 1.0.0) in build.rg, ridgunc, and stable whenever ridgunc or stable changes. (project, pedro@obdin.com) [lessons/pre-production-versioning-below-1-0.md](lessons/pre-production-versioning-below-1-0.md)
- Always scan raw source files and transitive .stable/deps/ modules for imports, and never register 0-arg ADT constructors with arity 0. (project, pedro@obdin.com) [lessons/preserve-transitive-deps-and-arity-invariants.md](lessons/preserve-transitive-deps-and-arity-invariants.md)
