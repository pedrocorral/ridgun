# core-lessons-learnt-notes

Generated by `aix lessons index` from `lessons/*.md`. Never edit this file: add, merge or prune the lesson files with
`core-lessons-learnt`, then run `aix lessons index`. Each line is a rule; open its file for why and when it applies.
`person` lessons are one user's preference: apply them when that author is the one you work with.

- Write all code examples, identifiers, and comments in technical documentation in English; reserve Spanish examples strictly for the Spanish book. (project, pedro@obdin.com) [lessons/english-code-examples-in-docs.md](lessons/english-code-examples-in-docs.md)
- Always pass -c user.name='Pedro Corral' and -c user.email='pedro@obdin.com' on every git commit command. (project, pedro@obdin.com) [lessons/git-commit-identity.md](lessons/git-commit-identity.md)
- Always use natural spaces instead of underscores in Ridgun function names, built-in calls, and tuple/sequence type signatures. (project, pedro@obdin.com) [lessons/natural-spaces-in-ridgun-names-and-types.md](lessons/natural-spaces-in-ridgun-names-and-types.md)
- Never overwrite bin/stable or bin/ridgunc until the newly built candidate binary in target/ has been 100% verified with check and test. (project, pedro@obdin.com) [lessons/never-overwrite-bin-until-verified.md](lessons/never-overwrite-bin-until-verified.md)
- Never scan compiled ELF binaries for zero/NOP padding caves, place executable code in ELF headers, or patch compiled binaries in-place. (project, pedro@obdin.com) [lessons/no-elf-cave-scanning-or-binary-patching.md](lessons/no-elf-cave-scanning-or-binary-patching.md)
